# Multimedia Authoring 2 HW1 - SVG Icons
This repository includes the first homework assignment in the Multimedia Authoring 2 class, which involves using 6 of our own SVG icons on a webpage and adding some sort of interactivity to those SVG icons.
## Installation
No installation required. Simply download the zip file and extract.

## Usage
Open index.html in the browser of your choice.
